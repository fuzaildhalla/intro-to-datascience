Python Program: Count Songs in Each Genre

# Import pandas
import pandas as pd

# Load the CSV file
df = pd.read_csv("spotify_data.csv")

# Count the number of songs in each genre
genre_count = df["genre"].value_counts()

# Display the result
print(genre_count)

Explanation:
- pd.read_csv() loads the CSV file into a DataFrame.
- df["genre"] selects the genre column.
- value_counts() counts how many songs belong to each genre.
- print() displays the number of songs in each genre.
